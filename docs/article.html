Why a builder escapes by default

An example page, itself built with Kumi

Hand-written HTML strings leak three bugs: unescaped content, unclosed tags, and nondeterministic attribute order. A builder closes the door on all three. The same call site reads as markup:

Node.div([.class("card")], [
    .h2([], text: title),
    .p([], text: body),
])

What you get

  • Auto-escaping text and attribute values
  • Auto-closing tags (void elements emit no close)
  • Deterministic, ordered attributes
